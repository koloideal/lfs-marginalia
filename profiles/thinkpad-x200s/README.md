# Профиль: ThinkPad X200s

Конфиги конкретной целевой машины — референс, а не модификация для
применения. Значения здесь (PARTUUID, разрешение экрана, имя ядра) привязаны
к конкретному железу и разметке; под другую систему они подставляются свои.
Применимые без изменений модификации живут в `mods/`.

## Железо

| Компонент | Что стоит | Что это значит для LFS |
|---|---|---|
| CPU | Intel Core 2 Duo (Penryn), x86_64 | старое, но полноценное 64-битное ядро; тесты в QEMU — с `-cpu Penryn` |
| GPU | Intel GMA 4500MHD (`i915`) | fbdev-консоль работает — boot-логотип и `fbcon=` применимы |
| Панель | 12.1", 1280×800 | отсюда `gfxpayload=1280x800x32` в grub.cfg |
| Загрузка | legacy BIOS, без UEFI | GRUB в BIOS-режиме, разметка MBR (`insmod part_msdos`) |

## Схема установки

Система собирается в raw-образе `lfs.img` на хосте (см. мод
`mods/07-chroot/lfs-chroot`), внутри образа два раздела:

| Раздел | Назначение | PARTUUID в образе |
|---|---|---|
| p1 | swap | `bace5795-01` |
| p2 | корень ext4 | `bace5795-02` |

Проверка итоговой системы — в QEMU со `snapshot=on`, затем образ
заливается на диск ноутбука (`zstd | ssh | dd`).

## Файлы и куда они ставятся

- **`fstab`** → `/etc/fstab` собранной системы (глава 9.3 книги).
  `PARTUUID` — идентификатор раздела из таблицы разделов самого диска
  (8-значная сигнатура MBR + номер раздела). Он «ездит» вместе с образом
  и не зависит от хоста сборки, но при пересоздании разметки меняется.

- **`grub.cfg`** → `/boot/grub/grub.cfg` (глава 10.4.4 книги).
  Второй пункт меню — аварийная оболочка с `init=/bin/bash` вместо init:
  при проблемах с загрузкой открывает root-shell напрямую.

- **`background.png`** → `/boot/grub/background.png`. Фон и шрифт из
  `loadfont` должны реально лежать по указанным в grub.cfg путям, иначе
  GRUB тихо покажет текстовое меню.

## Адаптация под другую машину

1. Скопировать директорию в `profiles/<имя-машины>/`.
2. Подставить свои PARTUUID в `fstab` и в `root=` grub.cfg — из `lsblk -o
   NAME,PARTUUID /dev/sdX` (для образа — после `losetup -P`).
3. Выставить `gfxpayload` под разрешение панели — доступные режимы
   показывает команда `videoinfo` в консоли GRUB.
4. Имя ядра в menuentry — `vmlinuz-<версия><CONFIG_LOCALVERSION>`; здесь
   `-lfs13.1-kolo` взят из `CONFIG_LOCALVERSION` в `.config`.
5. Параметр `fbcon=logo-pos:right,logo-count:1` в cmdline — из мода
   `mods/10-kernel/fbcon-logo-right`; на непропатченном ядре просто
   игнорируется.
6. UEFI вместо BIOS → разметка GPT, GRUB через `--efi-directory`,
   `insmod part_gpt` и соответствующий раздел книги.
