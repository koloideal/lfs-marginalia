# Профиль: ThinkPad X200s

Конфиги конкретной целевой машины. **Это референс, а не модификация для
применения.** Значения здесь (PARTUUID, разрешение экрана, имя ядра)
привязаны к конкретному железу и разметке; для другой системы они
подставляются свои. Модификации, применимые как есть, живут в `mods/`.

## Железо

| Компонент | Что стоит | Что это значит для LFS |
|---|---|---|
| CPU | Intel Core 2 Duo (Penryn), x86_64 | старое, но полноценное 64-битное ядро; тесты в QEMU — с `-cpu Penryn` |
| GPU | Intel GMA 4500MHD (`i915`) | fbdev-консоль работает — boot-логотип и `fbcon=` применимы |
| Панель | 12.1", 1280×800 | отсюда `gfxpayload=1280x800x32` в grub.cfg |
| Загрузка | legacy BIOS, без UEFI | GRUB в BIOS-режиме, разметка MBR (`insmod part_msdos`) |

## Схема установки

Система собирается в raw-образе `lfs.img` на хосте (см. мод
`mods/07-chroot/lfs-chroot`), внутри образа два раздела:

| Раздел | Назначение | PARTUUID в образе |
|---|---|---|
| p1 | swap | `bace5795-01` |
| p2 | корень ext4 | `bace5795-02` |

Проверка итоговой системы — в QEMU со `snapshot=on`, затем образ
заливается на диск ноутбука (`zstd | ssh | dd`).

## Файлы

### `fstab`

Устанавливается в `/etc/fstab` собранной системы (глава 9.3 книги).

PARTUUID — это идентификатор раздела из таблицы разделов **самого диска**
(8-значная сигнатура MBR-диска + номер раздела). Он «ездит» вместе с
образом и не зависит от хоста, на котором велась сборка. Однако при
пересоздании разметки сигнатура меняется. Актуальные значения:

```bash
lsblk -o NAME,PARTUUID /dev/sdX     # или для образа — после losetup -P
```

### `grub.cfg`

Устанавливается в `/boot/grub/grub.cfg` (глава 10.4.4 книги). Что здесь
специфично и что менять под другую машину:

- `gfxpayload=1280x800x32` — нативное разрешение панели X200s. Доступные
  режимы конкретной машины показывает команда `videoinfo` в консоли GRUB.
- `background_image /boot/grub/background.png` + `loadfont` — фон и шрифт
  должны реально лежать по этим путям, иначе GRUB тихо покажет текстовое
  меню.
- `fbcon=logo-pos:right,logo-count:1` в cmdline — параметр из мода
  `mods/10-kernel/fbcon-logo-right`. На непропатченном ядре он просто
  игнорируется.
- `root=PARTUUID=...` — тот же PARTUUID, что и в fstab.
- Второй пункт меню — аварийная оболочка: `init=/bin/bash` вместо init.
  При проблемах с загрузкой открывает root-shell напрямую.
- Имя ядра `vmlinuz-7.2.10-lfs13.1-kolo` — суффикс `-lfs13.1-kolo` из
  `CONFIG_LOCALVERSION` в .config ядра.

### `background.png`

Фон меню GRUB, размещается в `/boot/grub/background.png` на целевой
системе.

## Адаптация под другую машину

Скопировать директорию в `profiles/<имя-машины>/` и изменить:

1. PARTUUID — по выводу `lsblk` для своей разметки.
2. `gfxpayload` — под разрешение панели (`videoinfo` в консоли GRUB).
3. UEFI вместо BIOS → разметка GPT, GRUB через `--efi-directory`,
   `insmod part_gpt` и соответствующий раздел книги.
4. Имя и версию ядра в menuentry.
