# lfs-chroot — вход в chroot LFS-системы одной командой

В главе 7.4 вход в chroot это пачка команд из нескольких разделов книги:
смонтировать корень в `$LFS`, пробросить `/dev`, `/dev/pts`, `/proc`, `/sys`,
`/run`, `/dev/shm`, затем `chroot`. До конца сборки входить приходится
десятки раз. Скрипт делает всё за один запуск и при выходе снимает только
то, что смонтировал сам.

| | |
|---|---|
| **Этап** | глава 7.4 и далее при каждом входе в chroot (главы 8–11, отладка после сборки) |
| **Где** | host |
| **Проверено** | хост Arch Linux; версия LFS без разницы — обёртка над `mount`/`chroot` |
| **Требования** | LFS собирается в raw-образе через loop, **не на реальном разделе**; в образе `p1` — swap, `p2` — корень ext4; на хосте bash, util-linux, udevadm, sudo |
| **Риск** | низкий: чужие монтирования не трогает |
| **Откат** | `exit` — скрипт размонтирует и отключит то, что поднял сам |

## Применение

1. Задать пути в шапке скрипта:

   ```bash
   IMG=/home/lfs-build/lfs.img   # путь к raw-образу
   LFS=/mnt/lfs                  # точка монтирования корня
   ```

2. Запустить — при необходимости скрипт сам перезапустится через sudo:

   ```bash
   ./lfs-chroot
   ```

   Скрипт подключит образ через свободный loop-device, смонтирует корень
   и виртуальные ФС и откроет root-shell с промптом `(lfs chroot)` и чистым
   окружением: `HOME=/root`, `PATH=/usr/bin:/usr/sbin`,
   `MAKEFLAGS=-j<число ядер>` — как предписывает книга.

3. Работать внутри. По завершении — `exit`: скрипт размонтирует
   монтирования и отключит loop-device.

## Проверка

```bash
# внутри chroot:
ls /usr/bin/gcc        # тулчейн LFS виден
mount | grep /proc     # proc смонтирован
```

## Заметки

- Повторный запуск при живых loop и монтированиях **переиспользует** их:
  второй chroot откроется рядом, при выходе ничего не сломается.
- Если внутри остаются процессы других сессий — при выходе скрипт сообщит
  и оставит монтирования. Посмотреть остатки:

  ```bash
  findmnt -R /mnt/lfs                      # что осталось смонтированным
  losetup -j /home/lfs-build/lfs.img       # какой loop держит образ
  ```

- Если `$LFS` уже смонтирован с другого раздела — скрипт остановится,
  а не перемонтирует.
- Если LFS лежит на реальном разделе, а не в образе — скрипт не нужен
  (либо убрать из него часть с `losetup`).
- При другом номере корневого раздела поменять `${LOOP}p2` в скрипте.
- `udevadm settle` нужен, чтобы разделы `loopXpN` успели появиться в `/dev`
  до попытки mount.
