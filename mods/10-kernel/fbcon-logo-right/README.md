# fbcon=logo-pos:right

## Что это и зачем

При загрузке с framebuffer-консолью ядро рисует boot-логотип — по умолчанию
в левом верхнем углу, по одному экземпляру на каждое ядро CPU. У ядра давно
есть параметр `fbcon=logo-pos:center`, который двигает полоску логотипов
в центр экрана.

Этот патч добавляет третий вариант — `right`: логотипы выравниваются по
правому краю, оставаясь в верхней строке. На широком экране текст консоли
идёт слева, и картинка справа выглядит аккуратнее, не перекрывая сообщения
загрузки.

Изменение крошечное: новая переменная `fb_right_logo`, ветка в
`fb_show_logo()`, которая считает `dx = xres - ширина_логотипов`, плюс парсер
значения `right` и строка в документации.

## Совместимость

- Патч снят с ядра **7.2.10**. Код fbcon почти не меняется годами — на
  соседних версиях он почти наверняка наложится с fuzz, а если нет, правка
  элементарно переносится по контексту (три места: объявление extern, ветка
  в `fb_show_logo`, парсер в `fbcon.c`).
- От LFS-части ничего не требуется: это мод ядра, он одинаково работает на
  любом дистрибутиве, не только на LFS.
- Эффект есть только там, где работает fbcon. На машинах, где консоль живёт
  в DRM/KMS без fbdev-эмуляции, или на headless-системах логотипу рисоваться
  негде.

## Как применить

Из chroot, в корне распакованных исходников ядра:

```bash
cd /sources/linux-7.2.10

# автоматический вариант — скрипт сам проверит версию и выполнит dry-run:
/path/to/this/dir/apply.sh

# или вручную:
patch -Np1 --dry-run -i /path/to/fbcon-logo-right.patch
patch -Np1 -i /path/to/fbcon-logo-right.patch
```

Далее нужно убедиться, что в `.config` включён логотип, и собрать ядро
как обычно по книге:

```bash
grep -E 'CONFIG_LOGO(=|_)' .config
# должно быть: CONFIG_LOGO=y и хотя бы один CONFIG_LOGO_*=y
```

После установки ядра добавить параметр в cmdline (пример для GRUB):

```
linux /boot/vmlinuz-... root=... ro fbcon=logo-pos:right,logo-count:1
```

`logo-count:1` необязателен — ограничивает число логотипов одним, иначе
рисуется по логотипу на каждое ядро CPU.

## Как проверить, что сработало

- До загрузки: `grep fb_right_logo drivers/video/fbdev/core/fb_logo.c` —
  переменная есть, патч применён.
- После загрузки: логотип находится в правом верхнем углу.
- Контроль «это точно работает патч»: на непропатченном ядре значение
  `right` будет тихо проигнорировано, и логотип останется слева.

## Как откатить

Убрать `fbcon=logo-pos:right` из cmdline и перезагрузиться. Пропатченное
ядро без параметра ведёт себя как стоковое, пересборка не нужна.

## Заметки

- Патч в апстрим не отправлялся — живёт в этом репозитории.
- Комбинируется с модом `custom-boot-logo` из соседней директории: тот
  меняет *картинку* логотипа, этот — *позицию*.
