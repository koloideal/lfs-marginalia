# custom-boot-logo

## Что это и зачем

Логотип, который ядро рисует в углу экрана при загрузке (пингвин, по одному
на ядро CPU), — это файл `drivers/video/logo/logo_linux_clut224.ppm`
в исходниках ядра. При сборке он конвертируется в C-массив и зашивается
в бинарь. Подмена файла до `make` даёт собственную заставку.

В комплекте:

- `gen_logo.py` — генератор пиксель-арт логотипа «kolo's lfs» на чистом
  Python, без зависимостей. Пишет PPM в ASCII-формате P3.
- `kolo-lfs-kernel-logo.ppm` — уже сгенерированный файл, можно брать как есть.
- `kolo-lfs-kernel-logo.png` — та же картинка в PNG, для предпросмотра
  без открытия PPM.

## Совместимость

- Любая версия ядра, где есть `drivers/video/logo/logo_linux_clut224.ppm` —
  механика не менялась много лет.
- Ограничение формата CLUT224: палитра до 224 цветов. Комплектная картинка
  укладывается с запасом (7 цветов). Для собственного изображения из
  графического редактора нужно следить за числом цветов и сохранять в PPM.
- Логотип виден только на fbcon. При чистом DRM/KMS без fbdev-эмуляции
  или при загрузке со splash его не будет видно в любом случае.

## Как применить

Из chroot, в корне исходников ядра:

```bash
cd /sources/linux-7.2.10

# автоматический вариант — скрипт сохраняет оригинал и подменяет файл:
/path/to/this/dir/apply.sh                          # комплектным логотипом
/path/to/this/dir/apply.sh . /path/to/my-logo.ppm   # или своим файлом
```

Генерация собственной картинки (можно и на хосте — зависимостей нет):

```bash
python3 gen_logo.py        # создаст kolo-lfs-kernel-logo.ppm рядом
```

Текст задан переменной `text = "kolo's lfs"` внутри скрипта; цвета —
константами в шапке, размер холста — `WIDTH`/`HEIGHT` (по умолчанию 288×80,
стандартный размер логотипов ядра). Растровый шрифт свой, глифы — в словаре
`GLYPHS`; символы, которых там нет, нужно дорисовать.

Далее — проверка конфига и сборка по книге:

```bash
grep -E 'CONFIG_LOGO(=|_LINUX_CLUT224)' .config
# нужно: CONFIG_LOGO=y, CONFIG_LOGO_LINUX_CLUT224=y
```

## Как проверить, что сработало

- До сборки: `cmp <новый>.ppm drivers/video/logo/logo_linux_clut224.ppm`
  в дереве исходников — файлы идентичны.
- После загрузки: вверху экрана новый логотип вместо пингвина.

## Как откатить

```bash
mv drivers/video/logo/logo_linux_clut224.ppm{.orig,}
# пересобрать и переустановить ядро
```

## Заметки

- Комбинируется с соседним модом `fbcon-logo-right` — тот двигает логотип
  в правый верхний угол, этот меняет картинку.
- `logo-count:1` в cmdline убирает дубли логотипа на многоядерных CPU.
- Если при сборке ядро ругается на формат PPM — сконвертировать в бинарный
  P6: `pnmtopnm logo.ppm > logo_p6.ppm` (netpbm) или
  `convert logo.ppm logo.ppm` (ImageMagick).
