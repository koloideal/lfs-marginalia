# Имя мода — что делает одной строкой

Один-два абзаца для читателя без контекста: что делает, какую задачу
решает, почему возникло отклонение от книги. Без дублирования карточки
ниже и без жаргона (или с пояснением жаргона).

| | |
|---|---|
| **Этап** | глава X.Y книги LFS — в какой момент применять |
| **Где** | host / chroot / target |
| **Проверено** | на каких версиях реально собрано |
| **Требования** | условия, без которых мод бессмыслен или сломается |
| **Риск** | что случится в худшем случае |
| **Откат** | как вернуть как было |

## Применение

Нумерованные шаги строго в порядке выполнения: сначала подготовка
артефактов, потом вход в среду, потом применение, потом сборка. Команды
можно копировать; указывать, из какой директории они запускаются.
