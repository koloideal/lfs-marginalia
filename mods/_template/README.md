# Имя мода

## Что это и зачем

2–3 абзаца для читателя без контекста: что делает мод, какую задачу решает,
почему возникло отклонение от книги. Без жаргона или с пояснением жаргона.

## Совместимость

Раскрыть поля манифеста выше: на каких версиях проверено, где сломается,
какие опции конфигурации обязательны (например `CONFIG_FOO=y`).

## Как применить

Точные команды, которые можно скопировать. Указать, из какой директории
их запускать (например, «из корня распакованных исходников ядра в chroot»).

```bash
# шаг 1 — проверка, что мод применится
...
# шаг 2 — применение
...
```

Если есть `apply.sh` — описать, что он проверяет и что делает.

## Как проверить, что сработало

Команда или наблюдение, по которым видно, что мод заработал.

## Как откатить

Точные команды или «достаточно не передавать параметр X».

## Заметки
