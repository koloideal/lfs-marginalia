# mods/blfs — моды для BLFS

Сюда складываются модификации этапа [BLFS](https://www.linuxfromscratch.org/blfs/):
всё, что собирается поверх готовой базовой системы — Xorg, демоны,
графические окружения, сетевые сервисы.

Слой пока пустой. Правила наполнения те же, что для `mods/lfs/`
(см. `AGENTS.md` и `mods/_template/`): `mods/blfs/<NN>-<тема>/<имя-мода>`,
где NN — номер главы книги BLFS того издания, на котором мод проверен.
Номера глав BLFS сдвигаются между выпусками сильнее, чем в LFS, —
в карточке мода обязательно фиксировать версию книги.
