# custom-boot-logo — свой логотип ядра вместо пингвина

Подменяет файл `drivers/video/logo/logo_linux_clut224.ppm` в исходниках
ядра: при сборке он конвертируется в C-массив и зашивается в бинарь,
поэтому при загрузке вместо пингвина рисуется подменённая картинка.

| | |
|---|---|
| **Этап** | глава 10.4, сборка ядра — после распаковки исходников, до `make` |
| **Где** | chroot; генерацию картинки можно выполнять где угодно — чистый Python без зависимостей |
| **Проверено** | LFS 13.1 systemd, ядро 7.2.10, Intel i915 |
| **Требования** | в `.config` ядра: `CONFIG_LOGO=y` и `CONFIG_LOGO_LINUX_CLUT224=y`; python3 — только для генерации своей картинки |
| **Риск** | низкий: в худшем случае ядро соберётся со стоковым или кривым логотипом |
| **Откат** | вернуть `logo_linux_clut224.ppm.orig` на место, пересобрать ядро |

## Применение

1. Получить PPM-файл логотипа. Либо взять готовый
   `kolo-lfs-kernel-logo.ppm`, либо сгенерировать свой:

   ```bash
   cd <эта директория>
   python3 gen_logo.py    # создаст kolo-lfs-kernel-logo.ppm рядом
   ```

   В скрипте текст задан переменной `text = "kolo's lfs"`, цвета и размер
   холста — константами в шапке, глифы шрифта — в словаре `GLYPHS`
   (отсутствующие символы нужно дорисовать). Ограничение формата CLUT224:
   палитра до 224 цветов — комплектная картинка занимает 7. Своя картинка
   из графического редактора должна сохраняться в PPM и укладываться в лимит.

2. Войти в chroot и перейти в корень распакованных исходников ядра:

   ```bash
   cd /sources/linux-7.2.10
   ```

3. Подменить файл. Скрипт сохранит оригинал в `.orig` и предупредит,
   если нужные опции выключены в `.config`:

   ```bash
   /path/to/custom-boot-logo/apply.sh                          # комплектным логотипом
   /path/to/custom-boot-logo/apply.sh . /path/to/my-logo.ppm   # или своим файлом
   ```

   Вручную то же самое: `cp my-logo.ppm drivers/video/logo/logo_linux_clut224.ppm`.

4. Проверить конфиг и собрать ядро по книге:

   ```bash
   grep -E 'CONFIG_LOGO(=|_LINUX_CLUT224)' .config
   # нужно: CONFIG_LOGO=y, CONFIG_LOGO_LINUX_CLUT224=y
   ```

## Проверка

- До сборки: `cmp my-logo.ppm drivers/video/logo/logo_linux_clut224.ppm` —
  файлы идентичны.
- После загрузки: вверху экрана новый логотип вместо пингвина.

## Заметки

- Комбинируется с соседним модом `fbcon-logo-right`: тот меняет позицию
  логотипа, этот — картинку.
- `logo-count:1` в cmdline убирает дубли логотипа на многоядерных CPU.
- Если сборка ядра ругается на формат PPM — сконвертировать в бинарный P6:
  `pnmtopnm logo.ppm > logo_p6.ppm` (netpbm) или `convert logo.ppm logo.ppm`
  (ImageMagick).
- Логотип виден только на fbcon: при чистом DRM/KMS без fbdev-эмуляции или
  при загрузке со splash его не будет в любом случае.
- `kolo-lfs-kernel-logo.png` — та же картинка в PNG, для предпросмотра
  без открытия PPM.
