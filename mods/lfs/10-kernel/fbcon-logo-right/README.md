# fbcon=logo-pos:right — boot-логотип ядра в правом верхнем углу

Патч на ядро. Штатно boot-логотип (по одному на ядро CPU) рисуется в левом
верхнем углу, параметр `fbcon=logo-pos:center` двигает его в центр. Патч
добавляет третий вариант — `right`: полоска логотипов прижимается к правому
краю верхней строки и не перекрывает текст загрузки слева.

Изменение крошечное: переменная `fb_right_logo`, ветка в `fb_show_logo()`,
парсер значения `right` в `fbcon.c`, строка в `Documentation/fb/fbcon.rst`.

| | |
|---|---|
| **Этап** | глава 10.4, сборка ядра — после распаковки исходников, до `make` |
| **Где** | chroot |
| **Проверено** | LFS 13.1 systemd, ядро 7.2.10, Intel i915 (ThinkPad X200s) |
| **Требования** | `patch` в chroot; в `.config`: `CONFIG_LOGO=y`, `CONFIG_FRAMEBUFFER_CONSOLE=y` и один `CONFIG_LOGO_*=y`; рабочий fbcon на машине |
| **Риск** | низкий: без `logo-pos:right` в cmdline ядро ведёт себя как стоковое |
| **Откат** | убрать параметр из cmdline; патч откатывать не обязательно |

## Применение

1. В chroot перейти в корень распакованных исходников ядра:

   ```bash
   cd /sources/linux-7.2.10
   ```

2. Применить патч. Скрипт проверит, что текущая директория — дерево ядра,
   сверит версию и сделает `patch --dry-run` до реального применения:

   ```bash
   /path/to/fbcon-logo-right/apply.sh
   ```

   Вручную то же самое:

   ```bash
   patch -Np1 --dry-run -i /path/to/fbcon-logo-right.patch
   patch -Np1 -i /path/to/fbcon-logo-right.patch
   ```

3. Убедиться, что логотип включён в конфиге:

   ```bash
   grep -E 'CONFIG_LOGO(=|_)' .config
   # должно быть: CONFIG_LOGO=y и хотя бы один CONFIG_LOGO_*=y
   ```

4. Собрать и установить ядро по книге.

5. Добавить параметр в cmdline ядра. Пример для GRUB — в строку `linux`:

   ```
   linux /boot/vmlinuz-... root=... ro fbcon=logo-pos:right,logo-count:1
   ```

   `logo-count:1` необязателен: ограничивает число логотипов одним, иначе
   рисуется по логотипу на каждое ядро CPU.

## Проверка

- Патч применился: `grep fb_right_logo drivers/video/fbdev/core/fb_logo.c`.
- После загрузки: логотип в правом верхнем углу.
- Контроль: на ядре без патча значение `right` тихо игнорируется и логотип
  остаётся слева — если виден слева, загружено не то ядро.

## Заметки

- Патч снят с ядра 7.2.10. Код fbcon почти не меняется годами: на соседних
  версиях скорее всего наложится с fuzz, а при конфликте правка переносится
  по контексту — три места: объявление extern, ветка в `fb_show_logo`,
  парсер в `fbcon.c`.
- Это мод ядра, а не LFS: работает на любом дистрибутиве.
- Эффект есть только там, где работает fbcon. На чистом DRM/KMS без
  fbdev-эмуляции и на headless-системах логотипу рисоваться негде.
- Комбинируется с модом `custom-boot-logo`: тот меняет картинку логотипа,
  этот — позицию.
